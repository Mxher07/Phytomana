# Phytomana

![Phytomana](Logo.png)

*Phytomana* is an API mod for **SurvivalCraft 2**, inspired by the design philosophies of *Botania* from **Minecraft**.

---

## Overview

**Phytomana** brings nature-driven magical automation and utility systems to **SurvivalCraft 2**, providing a flexible foundation for mod developers and players who seek a more organic approach to tech and magic progression.
